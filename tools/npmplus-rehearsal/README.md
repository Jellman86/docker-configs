# Fresh NPMplus staging

Temporary Git-backed Dockhand project for the owner-authorised fresh replacement
of Quark NPM. Start with empty independent state and recreate routes/access
controls through the supported API. Do not mount/import original NPM state.

The proxy joins existing app bridges and the private CrowdSec API network.
Published ports bind host loopback only. Management must listen on the container
interface for bridge publishing. The image is pinned, AppSec/HTTP3 remain off and
the bouncer uses stream mode. The manifest is generated by
scripts/build-npmplus.py from stacks/ingress/npmplus-prestart.cjs.

The optional probe profile provides a client at the future tunnel address
172.18.254.11. Remove that owned fixture before assigning the address to the real
tunnel. Production keeps the ingress/crowdsec project identities. Remove staging
after acceptance. Lifecycle uses Git, passing CI and Dockhand only.

Prerequisites: fresh protected state, CrowdSec private API network and bouncer
registration, and encrypted Dockhand administrator/cookie/bouncer variables.
Issue one classic-profile certificate for *.pownet.uk plus pownet.uk and
carry that same state into production. Preserve the original proxy/state for
independently tested rollback. No application secrets belong in Git.
